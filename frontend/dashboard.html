Cara pakai (Mode Shortcut di SEB):
  1. Atur Provider, API Key, dan Model di dashboard ini.
  2. Aktifkan Auto Pilot Kuis bila ingin otomatis mendeteksi kuis & mengutamakan deadline.
  3. Gunakan shortcut keyboard di dalam SEB:
    • Alt + A : Toggle Auto Pilot
    • Alt + S : Start / Resume / Submit
    • Alt + P : Pause | Alt + X : Stop / Cancel
    • Alt + H : Toggle UI Panel (Unhide / Hide)
